# Система організації кулінарних рецептів

Навчальний проєкт з об’єктно-орієнтованого аналізу та проєктування: вебзастосунок на Python, FastAPI та PostgreSQL.

- [Застосунок: можливості, налаштування та запуск](recipe-app/README.md)
- [Архітектура системи](docs/architecture.md)
- [Діаграми C4 та UML](docs/diagrams)
- [Сценарій демонстрації](recipe-app/docs/demo.md)
- [Результати перевірок](recipe-app/docs/verification.md)

Код, міграції, тести та конфігурації запуску містяться в `recipe-app`. Лабораторні звіти та вимоги збережено в корені репозиторію.

Для нового середовища виконайте інструкцію налаштування з `recipe-app/README.md`: створіть `.venv`, установіть залежності, скопіюйте `.env.example` у `.env`, задайте власні паролі та підготуйте PostgreSQL. Локальні паролі, дані бази, завантажені фото й віртуальне середовище не включені до репозиторію.
