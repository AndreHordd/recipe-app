# Перевірка готовності

Дата завершення: 06.10.2026. Етапи 1–8 початкової архітектури реалізовано. Застосунок призначений для локального запуску та навчальної демонстрації.

## Відтворюваний запуск

Перевірено окрему копію вихідного коду без робочого `.env`, `.venv`, кешів і даних. Створено нове оточення Python 3.12.14, залежності встановлено з `requirements.lock`; `pip check` не знайшов несумісностей.

На PostgreSQL 17.11 створено порожню схему в окремій базі `recipes_test`. Справжні команди `scripts.migrate`, `scripts.seed` та `scripts.dev --prepare-only` завершились успішно. Seed запущено двічі: залишилося 3 користувачі, 5 категорій, 5 тегів, 18 інгредієнтів і 12 рецептів. Сервер із чистої копії запущено через `scripts.dev --no-reload`; браузерні сценарії виконано проти цієї копії.

Docker на цьому комп'ютері не встановлено, тому запуск контейнера не перевірявся. У README команда `docker compose up -d --wait db` очікує проходження healthcheck перед міграцією. Чистий запуск перевірено з наявною PostgreSQL.

## Автоматичні перевірки

- У новому оточенні успішно виконано всі **196 тестів**: 95 модульних і 101 інтеграційний.
- Перший прогін: 194 успішні тести й 2 помилки підготовки тимчасової папки перевірочного скрипту. Після створення папки повторно виконано саме ці два тести міграцій — обидва успішні. Код застосунку для цього не змінювався.
- `ruff check app scripts tests` — без помилок; `ruff format --check` — усі 60 Python-файлів відповідають форматуванню.
- Набір перевіряє сесії й права, Origin/CSRF, валідацію, стани рецептів, три способи пошуку, приватність колекцій, міграції, seed, модерацію й довідники. Відкат та одночасні зміни перевіряються справжніми підключеннями PostgreSQL.
- Є попередження Starlette про майбутню зміну бібліотеки HTTP-клієнта для тестів. На поточному зафіксованому наборі залежностей тести працюють.

## Браузер

У завершальній перевірці виконано гостьовий перегляд, невдалий і успішний вхід, створення чернетки, публікацію, редагування, пошук українською за інгредієнтом із тегом і часом, відновлення URL-фільтрів, створення колекції та повторне додавання рецепта без дубля.

Через дві вкладки відтворено конфлікт версії. У довідниках між відкриттями з'явились нові категорія й тег; друга вкладка зберегла їх у рецепті. Перша показала конфлікт, після оновлення додала ці значення до форми та успішно зберегла їх повторно. Ця перевірка підтвердила виправлення втрати посилань через застарілий довідник.

Форму рецепта, пошук і колекцію перевірено при ширині 390 px: горизонтального прокручування немає. Перехід від назви до опису клавішею Tab працює. На попередньому етапі також перевірено адміністративні вкладки клавіатурою, модерацію, український пошук користувачів та зміни довідників.

Робочу базу під час завершальної перевірки не змінено. Тимчасовий сервер зупинено, тестову схему прибрано, порт 8000 звільнено для PyCharm. Локальні скрипти, копія й знімки перевірки лежать у `.local`, яка виключена з вихідного коду.

## Межі реалізації

Готові функції початкового навчального обсягу. За наступним запитом додано фотографії, описані нижче. Рейтинги, імпорт рецептів, відновлення пароля через пошту та публічне розгортання залишаються поза обсягом. Для показу достатньо локального сервера, наявних користувачів і [сценарію демонстрації](demo.md).

## Розширення фотографій — 06.10.2026

Поточний набір після додавання фото: **242 успішні тести** (114 модульних, 128 інтеграційних). Додано 19 модульних і 27 інтеграційних сценаріїв. Перевірено JPEG/PNG/WebP, прозорість, EXIF, обмеження до декодування, анімацію, вміст, запис двох файлів, права full/thumbnail, Origin/CSRF/версії та фактичний розмір потоку. Справжня друга connection змінює або приховує рецепт перед CAS завантаження: нові файли прибираються, старі зберігаються. SQL-trigger перевіряє rollback, окремі сценарії — cleanup після commit без 500. Звичайні зміни рецептів не стирають `photo_key`.

Браузерна перевірка використовувала окрему схему `recipes_test` та окрему папку тестових фото. Перевірено часткове збереження при несправному файлі, повторне завантаження без нового рецепта й очищення помилки, PNG, заміну WebP зі збереженням незбереженого опису, повторну публікацію, гостьові основне фото й мініатюру. Форма, сторінка та каталог перевірені при 390 px без горизонтального прокручування. Використано програмно створене тестове зображення.

Виправлено кешування старого API-клієнта: importmap узгоджує версії спільних JavaScript-модулів, версія застосунку додається також до entry scripts та CSS. Початкова міграція 001 залишилась незмінною; фото додає міграція 002. Інструкції резервування та ручного прибирання — у [photos.md](photos.md).
